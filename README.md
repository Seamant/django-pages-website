# Django Pages Website

A simple Django project with three pages: Home, About, and Contact.

## Pages

- `/` — Home
- `/about/` — About
- `/contact/` — Contact

## Run locally

```bash
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install Django
.\.venv\Scripts\python.exe manage.py runserver
```
